# NESAQO STORE

متجر أحذية عربي ثابت مناسب للاستضافة على GitHub Pages.

## التشغيل

افتح `index.html` محليًا أو ارفع الملفات إلى مستودع GitHub.

## GitHub Pages

1. أنشئ Repository جديدًا.
2. ارفع `index.html` ومجلدي `css` و`js`.
3. من Settings → Pages اختر النشر من فرع `main` ومجلد `/root`.
4. احفظ وانتظر رابط الموقع.

## تعديل المنتجات

المنتجات موجودة في:

`js/app.js`

يمكنك تعديل:
- الاسم
- السعر
- الصورة
- الوصف

## تغيير WhatsApp

في أعلى `js/app.js` يوجد المتغير:

`WHATSAPP_NUMBER`

ضع رقم WhatsApp الخاص بالمتجر بصيغة دولية وبدون علامة `+`.

## ملاحظة

هذه النسخة لا تحتوي على قاعدة بيانات أو لوحة تحكم. الطلبات تُرسل مباشرة إلى WhatsApp، ولذلك فهي مناسبة كبداية مجانية على GitHub Pages.
